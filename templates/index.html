Specific Device

Use for one device that needs an exact identity, DHCP IP, or dedicated config file.

Generic Profile

Use for a group of devices with the same vendor class and shared config file.

How matching works: Specific MAC/Serial mapping is checked first. If no specific rule matches, the device falls back to a Generic Profile by vendor class.
Input rules
  • Required must be entered before saving.
  • Optional can be left blank; blank config uses the Generic Profile fallback.
  • Exact means the value must match the device value.
  • Pattern is used for vendor class / serial suffix; arbitrary * regex is not accepted.
  • Option 60 test Capture the real DHCP value before enabling a Serial or Generic rule.

Device matching reference

Use this before creating a Specific Device or Generic Profile.

  • Exact MAC address: matches the client hardware address exactly.
  • Pattern Serial number: matches the ending serial suffix in DHCP Option 60; regex is not supported for Serial.
  • Contains / Regex Vendor class: choose literal substring matching or validated regex in Generic Profile.
  • Exact Hostname: compared with the hostname returned by the health check.
